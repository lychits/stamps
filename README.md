# Коллекция марок Виктора

Публичный каталог 477 экземпляров: https://lychits.github.io/stamps/

Фотографии, описания, история выпусков, источники и справочные оценки. Поиск, фильтры и сортировка доступны без авторизации.

`catalog-source.json` — основной реестр; `catalog.json` — собранные данные; `research-report.md` — отчёт проверки. Все фотографии находятся в `assets/`.

27 октября 2026 года повторно просмотрены 477 изображений. Исправлены Маяковский N-6053-20, Ленин N-6051-06, номинал N-6081-08 и доплатная марка N-6081-10; сохранено исправление Жданова N-6051-14. Основания, открытые вопросы и журнал — в `Full_Visual_Audit_2026-10-27.md` и `.json`.

Автономный архив: https://lychits.github.io/stamps/catalogue-offline.zip

GitHub Actions при каждой публикации заново собирает HTML и автономный ZIP из текущего реестра и фотографий командой `python3 build_catalog.py` (Python 3, Pillow 12.3.0). Поэтому скачиваемый архив соответствует опубликованным исправлениям. Генерируемый ZIP не хранится отдельно в текущем дереве Git; исходные изображения и сборщик сохраняются в репозитории.

Сумма относится только к оценённой части коллекции, не является ценой продажи альбома. Ограничения указаны в карточках.
