# Коллекция марок Виктора

Интерактивный каталог 477 экземпляров: фотографии, описания, история выпусков,
источники определения и справочные оценки. Поиск, фильтры и сортировка доступны
на сайте.

Публичный сайт: https://lychits.github.io/stamps/

`catalog.json` — полный реестр; `research-report.md` — отчёт углублённой проверки;
`catalogue-offline.zip` — автономная версия каталога. Все изображения хранятся в
`assets/`.

Справочный ориентир относится только к оценённой части коллекции. Он не является
подтверждённой ценой продажи всего альбома. Подробности и ограничения указаны в
карточках.

Публикация выполняется через GitHub Actions. Миграция сверяет контрольную сумму
каждого файла. После первоначального переноса файлы и фотографии находятся в
этом репозитории; повторная публикация использует их локальные копии.
